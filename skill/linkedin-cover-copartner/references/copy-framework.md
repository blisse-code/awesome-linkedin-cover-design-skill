# Copy framework

## The five pieces a banner can carry

1. **Who you help** so the right visitor self-identifies.
2. **How you help** (doer, leader, advisor, teacher). Signals depth, not a menu.
3. **Value** the outcome of working with you. This is usually the hook.
4. **How to reach you** URL, or "see my Featured section" (one tap, no typing).
5. **Credential** a verifiable number or recognition.

## The tension to manage

"Rule of Three" advice (statement, proof, direction) and "clarity is king" pull against "five pieces". Resolve by merging, not stacking:

- One hook line carries value (and sometimes who).
- One small eyebrow carries who.
- One supporting line carries how, in plain first-person words.
- Proof and contact are quiet.

If a draft needs more than five text elements, cut. The first cut is usually the credential line; the second is the eyebrow.

## Hook tests

A good hook passes all four:
- **Transaction test:** does it say what someone gets? ("Complexity in. Clarity out." passes; a values statement like "Decisions that hold up" describes a belief, not an exchange.)
- **Universal test:** does it work for every target persona without explanation?
- **Ownership test:** could a competitor use it unchanged? If yes, sharpen.
- **One-second test:** readable at mobile scale (roughly 0.24x); 4 to 7 words.

Delivery-mode lists ("Case studies · Audits · Mentoring") read as a vendor menu. Replace with level + domain + stakes ("Senior UX & AI strategy for regulated products") or a first-person line that proves mode ("I lead design teams and still ship the work.").

## Persona test (show this table)

| Visitor | Scans for | Likely reaction | Reaches out? |
|---|---|---|---|
| Hiring manager / executive | judgement, seniority, risk | | |
| Client / founder | "can you fix my problem?" | | |
| Student / early career | taste, approachability | | |
| Partner / technologist | capability, credibility | | |

Be honest: a banner rarely triggers outreach on its own. Its job is to earn the scroll to headline, About and Featured.

## Scoring rubric for variations

| Criterion | Weight |
|---|---|
| Primary target is the focal point (hook or URL, as the user chose) | 25% |
| Mobile legibility at true size | 25% |
| Safe-zone compliance (photo, UI icons, crops) | 20% |
| Brevity, nothing competing | 15% |
| Positioning clarity for the stated audience | 15% |

Score 1 to 5 per criterion, show the weighted total, recommend one, and name the trade-off of the runner-up.

## Claims hygiene

- Every number must match resume, headline and website. Point out mismatches before publishing.
- No client logos without written clearance; employees of agencies are rarely allowed.
- No "click below"; banners are not clickable.
- No emoji in banner copy.
